# isaaclab-pixi-example

First of all, make sure that your computer respect the minim spec required to run isaacsim, documented in https://docs.isaacsim.omniverse.nvidia.com/latest/installation/requirements.html#system-requirements, and then run:

~~~
git clone https://github.com/traversaro/isaaclab-pixi-example/
cd isaaclab-pixi-example
./download_isaaclab.sh
pixi run isaacsim
~~~
